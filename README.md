# Homebrew Tap

Homebrew formulae maintained by Seongwoo Choi.

## agentrec

Install the latest published agentrec release:

```bash
brew install seongwoo-choi/tap/agentrec
```

Upgrade later releases:

```bash
brew update
brew upgrade agentrec
```

The formula installs prebuilt, checksummed archives published by
[`seongwoo-choi/agentrec`](https://github.com/seongwoo-choi/agentrec). The updater
runs hourly and can also be started manually from GitHub Actions.
